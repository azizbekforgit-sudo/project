## Цель

AgroVerse — рынок фермеров Узбекистана: фермер продаёт урожай напрямую, без перекупщиков, покупатель покупает прямо у фермера.
Аудитория — в основном люди старшего возраста с телефона, поэтому интерфейс простой: крупный текст, большие кнопки, подписи у иконок, три языка (узбекский, русский, английский).

## Нынешняя стадия

- **Ветка `claude/beautiful-ride-e8weqa` запушена, но НЕ слита в `main`.** В ней:
  1. Фото, чеки и файлы чата хранятся в Postgres (бывшая ветка `persistent-photos`).
  2. Закрыты дыры безопасности: удалены `/api/debug/admin-info` и `/api/debug/reset-admin`; пароли открытым текстом больше не хранятся и не отдаются, старые значения `plain_password` стираются при запуске; пароль админа не пишется в лог.
  3. Новый дизайн по макету владельца (6 экранов) — это **светлая** тема. Нынешние цвета стали **тёмной** темой.
  4. Кнопка «Написать продавцу» на странице товара: переписка до заказа.
  5. Помощник (ИИ) работает через Groq, при сбое Groq переключается на Gemini.
  6. Переписаны тексты рекламной страницы, добавлена ссылка «Отзывы и идеи».
- Владелец сказал «остальное решай сам». Что решено без него — в разделе «Решения без владельца».

## Активные файлы

Фронтенд (`agroverse front/`, vanilla JS SPA с hash-роутером):
- `index.html`:
  - скрипт в `<head>` ставит `<html data-theme>` до отрисовки, чтобы при загрузке не мигал экран;
  - порядок стилей: `style.css` → `farmer.css` → `theme-dark-compat.css` → `theme.css`.
- `css/theme.css` — **главный файл дизайна v3**:
  - токены обеих тем (`html[data-theme="light|dark"]`);
  - `--field` — зелёный для текста и иконок, `--fill` — зелёный для заливки кнопок;
  - верхнее меню `.topnav`;
  - главная `.hm-*`, рынок `.mk2-*`, карточка товара `.pc2`, страница товара `.pd2-*`;
  - мастер объявления `.wz-*`, кабинет `.cb-*`, сообщения `.ch-*`.
- `css/theme-dark-compat.css` — **сгенерированный** файл, руками не править. Это тёмные версии старых стилей, где цвета зашиты прямо (`#fff`, `#111827`): `style.css`, вставки в `admin.js` и `delivery.js`, inline `style="..."`. После правок старых стилей запустить из корня репозитория `python3 tools/gen_dark_compat.py`.
- `css/farmer.css` — старый слой стилей. Заливки переведены на `--fill` / `--fill-deep`, текст на жёлтом — на `--on-sun`.
- `js/auth.js`:
  - `Theme` (get / set / toggle, запоминается в `localStorage` под ключом `av_theme`; пока человек сам не выбрал — тема как в телефоне);
  - `buildHeader()` — верхнее меню на ПК, нижняя панель на телефоне;
  - «Меню»-шторка: выбор темы и «Отзывы и идеи»;
  - `SOCIAL.feedback` — ссылка на отзывы.
- `js/i18n-v3.js` — все новые тексты на трёх языках и новые тексты рекламной страницы. Подключается последним из словарей и перезаписывает ключи.
- `js/pages/`:
  - `home.js` — первый экран, плитки категорий, свежие объявления, календарь поля, помощь;
  - `catalog.js` — рынок: поиск, фильтры слева, сортировка, `productCardHtml()`, хелперы `unitLabel` / `catLabel` / `fmtNum` / `priceHtml`;
  - `product.js` — галерея, характеристики, карточка продавца, «Написать продавцу», заказ;
  - `product-new.js` — мастер «Новое объявление» в 3 шага: о товаре → цена и количество → проверка;
  - `profile.js` — «Кабинет фермера» с вкладками `?tab=overview|listings|profile`;
  - `chats.js`, `chat.js` — «Сообщения»: список слева, переписка справа, на телефоне по очереди.
- Не переделывались (работают в обеих темах за счёт сгенерированного файла): `orders.js`, `cart.js`, `wallet.js`, `tariffs.js`, `ai.js`, `admin.js`, `delivery.js`, `login.js`, `register.js`, `landing.js` (у последних трёх добавлена только кнопка темы).

Бэкенд (`agroverse back/`, FastAPI + async SQLAlchemy + Postgres):
- `app/main.py` — миграции через `safe_exec`:
  - `chats.order_id` может быть пустым, добавлен `chats.product_id`;
  - очистка `plain_password`.
- `app/routers/chats.py` — `POST /api/chats/product/{id}`: один чат на пару «покупатель — товар». До заказа телефоны участников не отдаются.
- `app/routers/ai.py` — `_ask_groq` (OpenAI-совместимый API, модели по очереди), затем `_ask_gemini`, затем `_ask_grok`.
- `app/config.py`, `.env.example` — `GROQ_API_KEY`, `GROQ_MODELS`.
- `tools/gen_dark_compat.py` (в корне репозитория) — генератор `theme-dark-compat.css`.

Переменные окружения на Render:
- `GROQ_API_KEY` — **нужно добавить** (ключ владелец прислал в чате; в репозиторий не коммитить);
- `GEMINI_API_KEY` — запасной вариант;
- `ADMIN_PASSWORD` — **обязательно задать**: иначе пароль админа `admin123` (в логе теперь есть предупреждение);
- по желанию `GOOGLE_CLIENT_ID`, `ESKIZ_EMAIL`, `ESKIZ_PASSWORD`;
- `WIPE_PRODUCTS` — удалить, если ещё задана.

## Failed attempts / ограничения

- Из контейнера закрыты `api.groq.com`, CDN шрифтов и иконок (cdnjs, Google Fonts, unpkg). Groq вживую не проверен — только заглушкой. Для скриншотов FontAwesome и шрифты брались из npm.
- Генерация картинок недоступна: в сессии нет такого инструмента, домены OpenAI закрыты. Фотостоки (Unsplash, Pexels, Pixabay, Wikimedia) тоже закрыты сетевой политикой, поэтому картинку первого экрана нарисовали сами (SVG). Если владелец захочет настоящее фото — положить в `assets/` и заменить `hero-dusk.svg` в `home.js` и в `.lp-hero-bg` в `farmer.css`.
- Старые фото товаров на Render восстановить нельзя.
